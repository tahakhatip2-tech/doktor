## 🔌 تكاملات API المطلوبة

```typescript
// endpoints جديدة تحتاج إضافتها في src/api/

// patient.api.ts
POST /patient/appointments/[id]/cancel       // إلغاء موعد مع سبب
GET  /patient/clinics/[id]/available-slots   // الأوقات المتاحة
POST /patient/clinics/[id]/reviews           // إرسال تقييم
GET  /patient/clinics/[id]/reviews           // جلب تقييمات
GET  /patient/profile                        // بيانات المريض
PUT  /patient/profile                        // تعديل البيانات
GET  /patient/medical-records               // السجلات الطبية
GET  /patient/prescriptions                 // الوصفات
POST /patient/prescriptions/[id]/send-to-pharmacy // إرسال للصيدلية

// doctor.api.ts
GET  /appointments/stats                     // إحصائيات
POST /appointments/[id]/complete             // إتمام موعد + وصفة
GET  /contacts/[id]                          // تفاصيل مريض
GET  /financial/summary                      // ملخص مالي

// pharmacy.api.ts
GET  /pharmacy/prescriptions                 // وصفات الصيدلية
PUT  /pharmacy/prescriptions/[id]/dispense  // صرف وصفة
```

## 🛠️ أوامر الفحص والتشغيل (Testing & Running Commands)

هذه قائمة بأهم الأوامر المستخدمة لفحص وتشغيل التطبيق:

### 1️⃣ فحص الأكواد (Type Checking & Linting)
للتأكد من عدم وجود أي أخطاء برمجية في `TypeScript` قبل بناء التطبيق:
```bash
# فحص الأنواع بدون توليد ملفات
npx tsc --noEmit

# إصلاح بعض مشاكل الـ Linting (إن وجدت)
npm run lint
```

### 2️⃣ تشغيل التطبيق في بيئة التطوير (Development)
لبدء خادم `Expo` وتشغيل التطبيق محلياً:
```bash
# تشغيل خادم Expo الأساسي
npx expo start

# تنظيف الكاش وتشغيل الخادم (يُنصح به عند تغيير المكتبات)
npx expo start -c
```

### 3️⃣ بناء التطبيق (Build)
لإنشاء نسخة تجريبية أو نهائية للتطبيق باستخدام `EAS (Expo Application Services)`:
```bash
# بناء نسخة Android بصيغة APK للتجربة المحلية
npx eas-cli@latest build -p android --profile preview

# بناء نسخة Android بصيغة AAB للرفع على Google Play
npx eas-cli@latest build -p android --profile production

# عرض تفاصيل بناء معين (استبدل UUID بمعرف البناء)
npx eas-cli@latest build:view <UUID> --json
```
